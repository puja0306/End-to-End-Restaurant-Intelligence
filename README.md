# End-to-End-Restaurant-Intelligence
An end-to-end ML &amp; data analytics project featuring rating prediction (regression), content-based recommendation (TF-IDF &amp; cosine similarity), cuisine classification, and geospatial analysis using Python, Scikit-Learn, and Folium.
Project Overview

This project consists of 4 primary modules:

Task 1: Rating Prediction (Regression)

Preprocessed restaurant data by handling missing values, one-hot encoding, and feature scaling.

Trained and compared Linear Regression, Decision Tree, and Random Forest Regressors.

Evaluated models using MAE, MSE, RMSE, and R2 score, followed by feature importance extraction.

Task 2: Content-Based Restaurant Recommendation Engine

Engineered combined text metadata profiles including Cuisines, City, Price Range, and Delivery status.

Implemented a TF-IDF Vectorizer and calculated Cosine Similarity to match user queries with top-rated restaurant alternatives.

Task 3: Cuisine Classification

Built a multi-class classification model using Logistic Regression and Random Forest Classifier.

Categorized restaurants into their primary cuisine types and evaluated precision, recall, F1-score, and confusion matrices.

Task 4: Location-Based Spatial Analysis

Mapped restaurant geographic density and clusters using Folium interactive maps.

Evaluated performance metrics across cities and localities, including average rating and price tier distributions.

Tech Stack and Libraries

Language: Python

Data Manipulation: pandas, numpy

Machine Learning: scikit-learn

Visualization: matplotlib, seaborn, folium

Environment: Google Colab, Jupyter Notebook
